The first release of Comte Log Analyzer: a desktop app that turns Unity's `Editor.log` and `Player.log` into something a person can read.

**Windows only.** Download `comte-log-analyzer-v0.1.2-windows-x64.zip` below, unzip it, and run `comte-log-analyzer.exe`. With no file given it opens your current Unity `Editor.log`; drop any other log onto the window. `comte.exe` is the command-line version (`--summary`, `--compare`, `--report`).

## What it does

- Finds your Editor and Player logs on its own, plus related logs such as `upm.log` and the import workers' logs.
- Groups a log into a readable timeline (Startup, compiles, domain reloads, Play mode, scenes), with engine chatter hidden and repeats collapsed.
- Explains what went wrong: a one-line verdict, native crashes traced to a GPU driver, your IL2CPP code, the engine or a plugin, known problems such as out of memory or a removed graphics device, and where Unity got stuck ("Stopped while importing Assets/Hero.fbx").
- Opens logs too large for an editor, from their end, and names the message that filled the file.
- Saves, shares and compares: sessions with notes, tags and pins, redacted by default; a support pack zip; Markdown or Slack reports; a comparison with the previous run.
- Notices when domain reloads and compiles get slower than your earlier sessions, and shows where reload time goes.

## Tested with

- **Player.log:** logs from 25 games built with Unity 2019.4, 2020.3, 2021.3, 2022.3 and Unity 6 (6000.0, 6000.2, 6000.3).
- **Editor.log:** Unity 6000.3. Older Editor versions haven't been checked against real logs yet.

Building from source needs Rust 1.95 or newer. The executables are not code-signed, so Windows SmartScreen may ask you to confirm the first time you run them.
